Open AI-generated HTML locally.

HTMLViewer helps you import HTML and HTM files from Files, preview local pages with WebKit, and review reports, prototypes, dashboards, teaching pages, and offline documents on iPhone.

HTMLViewer 可以从“文件”App 导入 HTML/HTM 文件，并用系统 WebKit 在 iPhone 上预览本地页面，适合查看 AI 生成的报告页、网页原型、数据看板、教学页面和离线文档。

Support

技术支持

Use these checks if a local page does not display as expected.

如果本地页面显示效果不符合预期，可以按下面的步骤排查。

  • Import the whole folder. If the page depends on CSS, JavaScript, or images, import the containing folder instead of a single HTML file.
  • 导入整个文件夹。 如果页面依赖 CSS、JavaScript 或图片，请导入包含这些资源的完整文件夹。
  • Use relative paths. Local pages work best when linked resources use paths relative to the HTML file.
  • 使用相对路径。 本地页面中的资源链接采用相对 HTML 文件的路径时，显示更稳定。
  • Reimport after edits. If a page was changed in another app, import the updated file or folder again.
  • 修改后重新导入。 如果页面在其他 App 中被修改，请重新导入更新后的文件或文件夹。

Privacy: HTMLViewer focuses on local viewing. It requires no account. Imported files are stored in the app sandbox on your device for offline access.

隐私说明：HTMLViewer 专注本地查看，无需账号登录。导入的文件会保存在设备上的 App 沙盒中，便于离线访问。
